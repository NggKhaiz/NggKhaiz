Tổng quan

Mình muốn biết code bị làm rối đang giấu gì, nên viết luôn công cụ đi tìm. Repo gồm `obf-scanner.py`, một thư mục `ravenst`, `kill.txt` và LICENSE.

Vì sao có nó

Đọc code lạ là cách nhanh nhất để hiểu một hệ thống. Viết scanner buộc mình phải hiểu từng kiểu làm rối thay vì đoán.

Cách nó chạy

Một script Python chạy được bằng CLI, không cần service. Đẩy lên GitHub là dùng được, không có bước build.
